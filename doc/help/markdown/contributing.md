# Contributing

The **Tanglet** development is maintained in a
[Github repository](https://github.com/gottcode/tanglet/).

## Contributing with code

If you have a Github account, feel free to fork the project, apply and commit
your changes and open a Pull Request. This is the preferred way.

## Issue tickets

You found a bug, like to request a new feature or have any other suggestion?
Please got to [our issue tracker](https://github.com/gottcode/tanglet/issues)
and open a new one by clicking on **New issue** in the top right corner of the
page. This also applies for the documentation, if parts are confusing or
missing, or for wrong translations. Regarding incomplete translations: Don't
treat it as a bug worth to be filed. Our translators don't always have as much
time as needed, so translations may be incomplete.

## Translations

**Tanglet** is available in various languages. The appropriate `.ts` and `.po`
files are maintained at
[Transifex](https://explore.transifex.com/gottcode/tanglet/). If you like to
contribute to translations, register or sign in there, join a translation team
or create a new one for your desired language, if needed.

For the translations itself, Transifex offers a web-based editor. If you prefer
to work on the files directly, you can also download and edit them locally in
your preferred tool.

Although **Tanglet** is not part of any integrated desktop environment, please
always try to follow the basic rules of well-known translation teams for your
language, for example, those of the [KDE](https://l10n.kde.org/teams-list.php)
or [GNOME](https://l10n.gnome.org/teams/) teams.
