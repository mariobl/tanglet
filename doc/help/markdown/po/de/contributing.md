# Mitwirken

Die Entwicklung von **Tanglet** wird in einem
[Github-Repository](https://github.com/gottcode/tanglet) verwaltet.

## Code beitragen

Wenn Sie ein GitHub-Konto haben, können Sie das Projekt gerne forken, Ihre
Änderungen anwenden und committen und anschließend einen Pull Request
öffnen. Dies ist die empfohlene Vorgehensweise.

## Fehĺerbericht-Tickets

Haben Sie einen Fehler gefunden, möchten Sie eine neue Funktion vorschlagen
oder haben Sie sonstige Anregungen? Besuchen Sie bitte [unseren
Issue-Tracker](https://github.com/gottcode/tanglet/issues) und erstellen Sie
ein neues Ticket, indem Sie oben rechts auf der Seite auf **New issue**
klicken. Dies gilt auch für die Dokumentation, falls Teile davon unklar oder
unvollständig sind oder fehlerhafte Übersetzungen vorliegen. Unvollständige
Übersetzungen: Bitte betrachten Sie dies nicht als Fehler, der gemeldet
werden muss. Unsere Übersetzer haben nicht immer ausreichend Zeit, daher
können Übersetzungen unvollständig sein.

## Übersetzungen

**Tanglet** ist in verschiedenen Sprachen verfügbar. Die entsprechenden `.ts`- und `.po`-Dateien werden bei [Transifex](https://explore.transifex.com/gottcode/tanglet/) verwaltet. Wenn Sie an den Übersetzungen mitwirken möchten, registrieren Sie sich dort oder melden Sie sich an, treten Sie einem Übersetzungsteam bei oder erstellen Sie bei Bedarf ein neues für Ihre gewünschte Sprache.

Für die Übersetzungen selbst bietet Transifex einen webbasierten Editor
an. Wenn Sie die Dateien lieber direkt bearbeiten möchten, können Sie sie
auch herunterladen und lokal mit Ihrem bevorzugten Programm bearbeiten.

Obwohl **Tanglet** nicht Teil einer integrierten Desktop-Umgebung ist,
versuchen Sie bitte stets, die Grundregeln anerkannter Übersetzungsteams für
Ihre Sprache zu befolgen, beispielsweise die der
[KDE](https://l10n.kde.org/teams-list.php)- oder
[GNOME](https://l10n.gnome.org/teams/)-Teams.
