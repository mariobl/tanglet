# Konfiguration

Um **Tanglet** zu konfigurieren, öffnen Sie das **Einstellungen**-Menü. Die
folgenden Einträge werden angezeigt:

* **Maximale Punktzehl zeigen** – Sie können aus drei Optionen für die Statuszeile am unteren Rand es Fensters wählen:  

![Liste der maximalen
Punktzahlen](./figures/tanglet_toggle_maximum_score_display.png)
    
   * **Nie** – Sie sehen die Wortlängen und die Anzahl der Wörter, die Sie
     für jede Länge gefunden haben.

**Spielende** – Am Ende des Spiels sehen Sie die pro Wortlänge enthaltenen Wörter und die Anzahl der Wörter, die Soie gefunden haben.

   * **Immer**: Das vorstehend für **Spielende** beschriebene Verhalten ist
     immer sichtbar.

Die Sichtbarkeit der Wörterzahlen-Statusleiste kann mit **Wörterzahlen
zeigen** ein- oder ausgeschaltet werden.

![Wortanzahl-Statuszeile](./figures/tanglet_word_counts.png)

**Übersehene Wörter zeigen** – Zusätzlich zur Liste der gefundenen Wörter in der Seitenleiste wird ein Reiter namens **Übersehen** angezeigt. Dieser Reiter ist bis zum Ende des Spiels inaktiv.

**Spielfeldsprache** – Sie können die Spielfeldsprache wählen, indem Sie auf die Auswahlliste klicken und aus den verfügbaren Sprachen wählen. Außerdem haben Sie einige zusätzliche Optionen:

![Spracheinstellungen](./figures/tanglet_board_language.png)

Sie können die Dateipfade für **Würfel**, **Wortliste** und **Wörterbuch**
ändern, indem Sie die Pfade manuell eingeben oder auf die entsprechenden
**Auswählen…**-Knöpfe klicken, um einen Dateiauswahldialog zu öffnen. Um
alle Einstellungen auf die Standardwerte zurückzusetzen, klicken Sie unten
links im Fenster auf **Voreinstellungen**. Wie gewohnt können Sie die
Bearbeitung der Einstellungen mit dem Knopf **Abbrechen** beenden und die
Änderungen mit **OK** übernehmen. Ihre Änderungen werden beim nächsten Start
von **Tanglet** angewendet.

Unter **Anwendungssprache** können Sie die Sprache der Benutzeroberfläche
ändern. Das Einstellungsfenster öffnet sich mit dem Knopf
**Systemsprache**. Klicken Sie darauf, um die gewünschte Sprache aus dem
Auswahlmenü zu wählen. Wiederum werden Ihre Änderungen erst beim nächsten
Start von **Tanglet** wirksam.

Nicht alle der übersetzten Beschriftungen kommen aus **Tanglet** selbst. Da
einige davon von den darunter liegenden **Qt**-Bibliotheken bereitgestellt
werden, kann es vorkommen, dass sie noch in der Systemsprache angezeigt
werden. Vielleicht ist Ihnen der folgende Befehl bekannt, mit dem eine
Anwendung mit einer abweichenden Spracheinstellung geöffnet werden kann:
